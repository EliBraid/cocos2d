# 微光林地 v0.3：结构与制作说明

本版只打磨一只狐狸和一块森林空地。参考《咩咩启示录》已分析到的分层场景、骨架角色、身体与表情分轨、草木摆动和局部光影思路，使用原创图像与自写 Cocos 代码实现；未把原作资源或反编译代码放入工程。旧版营地和养成玩法保留在 Camp 场景，本版默认进入 Forest。

## 角色与动画

`ForestPetView` 使用 Cocos 原生 `sp.Skeleton` 和实时 Spine 4.2 Runtime。角色有28根骨骼、16个插槽、前后两套皮肤，正面10个加权网格附件。身体轨道播放动作，表情轨道独立处理眼睛与嘴部缩放，第三轨道处理视线。待机包含原生网格 deform 时间线；呼吸、耳朵、尾巴和围巾有各自的骨骼运动。

19个动画片段包括待机、行走、起步、停止、转向、攻击、受击、开心、嗅闻、睡眠、醒来，5种表情片段和3种视线片段。每个攻击在原生 `strike` 事件处结算一次命中；重复攻击按 attackId 重新开始播放，避免连续练剑只响应第一刀。原生脚步事件触发尘土。

角色先由独立相机绘制进 RenderTexture，再作为面向世界相机的角色平面参与3D深度排序。前后方向切换皮肤，左右方向翻转；没有制作八方向动画。JSON、atlas、PNG、拆件和生成脚本都可编辑，未提供 Spine 编辑器保存的 `.spine` 工程。

## 场景、光影与交互

场景用 XZ 地面坐标和倾斜正交相机呈现；地面、远近树木、草、蕨类、石头、火把、训练靶和核心独立摆放。树木、角色与道具参与深度遮挡；前景树遮住角色时使用抖动透明。点击目标环也在真实地面上绘制并参与深度测试，不会叠在角色脸上。相机有轻微跟随与近景查看。草木顶点受风摆动，草丛接触由弹簧状态驱动弯曲，有进入/离开迟滞，避免边界抖动重复触发。

`ink-light.effect` 按世界位置计算昼夜环境色、火光距离衰减及闪烁。树木、角色和道具的轮廓贴图投影配合软接触阴影，夜晚改变投影方向。火焰本身也由原生 Spine 播放；火星、萤火虫、飘叶使用固定节点池循环更新。训练靶受击产生回弹和斩击反馈。点击篝火会先寻路靠近，再嗅闻停留。

这是为手绘平面素材设计的定制色彩受光和贴图投影，没有使用物理材质、法线光照或实时阴影贴图。背面换肤、场景几何与光影规则是本工程的实现，不声称与原作内部系统完全相同。

## 代码入口

| 文件 | 责任 |
| --- | --- |
| `assets/scripts/ForestSlice.ts` | 启动资源、竖屏UI、点选与互动调度 |
| `assets/scripts/ForestLogic.ts` | 地面寻路、动作状态、命中去重、草丛弹簧 |
| `assets/scripts/ForestPetView.ts` | 原生 Spine、换肤、分轨动画与事件 |
| `assets/scripts/ForestWorld.ts` | 3D平面、相机、分层遮挡、灯光参数、环境动态 |
| `assets/resources/forest/ink-light.effect` | 顶点风摆、接触弯曲、局部火光与阴影材质 |
| `tools/build-forest-assets.mjs` | 从原创透明图集提取完整拆件 |
| `tools/build-forest-rigs.mjs` | 生成狐狸与火焰的 Spine 运行数据 |
| `tools/verify-forest.mjs` | 点击真实 Cocos UI，验证动画、表情和场景交互 |

## 检查与范围

本地 Windows Chrome 软件 WebGL：18项单元测试通过，Creator 3.8.8 CLI 构建通过，9项浏览器交互检查通过，运行控制台无错误或警告。检查实际原生骨骼值和 deform 数组随时间变化、前后换肤、5次训练命中、草丛触碰、夜色、篝火、睡眠/唤醒、390×844竖屏点击。报告见 `forest-verification/runtime-verification.json`；录屏为实际 Cocos 运行结果。

本版没有新增养成经济、多人服务或正式战斗关卡，暂无声音，也未做微信小游戏与手机硬件的性能验证。动画是可继续打磨的首版。场景以运行时创建，编辑器静态画布只显示启动结构；运行时节点可在调试层级检查。

原画通过内置 image_gen 制作，提示词、输入和固定结果见 `forest-v03-art-prompts.json`，运行时无需图像生成服务。
