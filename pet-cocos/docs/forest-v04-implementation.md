# 微光林地 v0.4：按参考实现复核后的修改

本版沿用自己的 Cocos 工程和原创狐狸。参考依据为本地《咩咩启示录》的 REA 调用、相机序列化数据和原始骨架动作取样；未移植原游戏贴图、骨架或反编译代码。

## 狐狸完整感

重新处理为更接近用户认可原画的三分之四朝向、短壮身体和大头比例。躯干、左臂及双腿保持连续绘画；右侧持剑手臂的根部放到身体与围巾下面；尾巴根部由身体遮盖。头部连同耳朵保持完整轮廓，耳朵仍通过网格局部权重运动。修正了素材格子越界导致的脚底裁切，并采用严格透明轮廓导入，过滤外部光晕。

原生 Spine 4.2 仍负责播放。新骨架使用28根骨骼、6个插槽、前后两套皮肤和19个动画片段。三角网格在耳朵、肩部、脚部等部位增加控制点，用Delaunay三角化连接，不再把各截肢体分别缩放再拼接。前向身体连续加权，背向使用完整绘画网格。

表情在单独轨道切换完整头部附件，以保持每种表情的完整画面；它不是眼睛、嘴巴各自独立拆件的面部绑定。待机有眨眼、呼吸、视线小幅移动、耳朵/尾巴与围巾运动；跑步重做了身体升降与压缩、头部反应、腿部摆动及脚部补偿，尾巴和围巾错开相位。挥剑时切换手臂前后绘制顺序，原生 strike 事件仍负责命中结算。

## 场景空间

世界相机改为透视投影，竖屏视野角43°。这适合当前样板的尺寸与构图，未机械照搬原作60°的保存值。树木、草丛与角色按用途设置不同倾角，并围绕竖直轴朝向镜头；不再让所有平面完全贴着相机方向。新增“视角”按钮，在两个真实相机位置间过渡，可观察物件之间的视差。

前景树、互动空地、石阶高台与远景树墙构成分层。高台有真实顶面与侧面，六级石阶各抬升0.12世界单位，总高0.72；点击通过射线与阶梯高度场求交，角色和地面提示落在对应高度。新增远景树墙、深度雾色与面朝向明暗差，保留昼夜过渡、局部火光、轮廓投影、草丛接触、火焰Spine和环境粒子。

当前光照仍是为手绘素材制作的环境色/局部受光与贴图投影，没有声称复刻原作的整套 stencil、LUT 或阴影管线。

## 验证与入口

使用 Cocos Creator 3.8.8 打开本工程的 `assets/scenes/Forest.scene`。默认构建目录为 `build/forest-v04`，启动 `tools/serve.ps1` 后访问 `http://127.0.0.1:8394/`。旧版静态构建 `build/forest-web` 和旧交付ZIP仍保留，可与8393上的旧版对照。

`tools/verify-forest-v04.mjs` 检查真实Cocos画布：透视与相机切换、原生网格形变、表情、前后朝向、台阶拾取与角色高度、草丛接触、连续五次命中、昼夜、篝火和390×844竖屏操作。截图、实际录屏与报告保存于 `docs/forest-v04-verification`。源码类型检查和20项逻辑测试另行执行；自动检查不能代替轮廓、接缝、落脚和动作节奏的画面复核。

素材通过内置 image_gen 制作；原图、拆件和完整提示词固定保存。运行不需要生成服务。交付为运行数据 JSON/atlas/PNG 和脚本，不包含 Spine 编辑器保存的 `.spine` 文件。当前仍是单宠单场景样板，未进行微信小游戏手机硬件性能验证。
