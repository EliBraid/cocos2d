## 运营要改的集合

每条记录都可以加 `"enabled": false` 临时下架。

### notices 公告（登录后弹出，每条只弹一次）
```json
{ "_id": "open-1", "title": "欢迎来到灵爪守望", "body": "正文，\\n 换行" }
```
发新公告：新建一条、换一个新的 `_id`。

### events 限时活动（主城顶部活动条）
```json
{ "_id": "newyear", "name": "新春庆典", "desc": "冒险金币 ×2", "icon": "star",
  "mods": { "coins": 2, "hatchCost": 0.5, "towerTries": 2 },
  "from": "2027-02-05", "to": "2027-02-12" }
```
- `mods`：`coins` 金币倍率、`hatchCost` 孵化价格倍率、`towerTries` 试炼额外次数，按需填。
- 日期活动用 `from`/`to`；每周固定活动用 `"weekdays": [6,0]`（0 = 周日）。
- 用相同的 `_id` 可以覆盖内置的每周活动（`weekend-coins`、`hatch-day`、`tower-friday`）。

### mails 邮件（所有玩家的邮箱里都会出现）
```json
{ "_id": "fix-1101", "from": "运营组", "title": "维护补偿", "body": "感谢耐心等待", "b": { "coins": 500, "stamina": 30 } }
```

### codes 兑换码（`_id` 就是兑换码，不区分大小写）
```json
{ "_id": "LINGZHAO", "b": { "coins": 888, "food": 20 } }
```
奖励字段 `b` 可以用：`coins` 金币、`food` 食物、`stamina` 体力、`mats`（`{"wood":10,"ore":10,"hide":10,"crystal":2}`）、`gems`（`{"ruby1":2}`）、`pet` 宠物（如 `"bunny"`）。
注意：兑换码列表会发到玩家手机上校验，懂技术的人能看到全部码。所以只适合做"公开福利码"，不要用来发高价值奖励。

## 只看的集合
| 集合 | 内容 |
|---|---|
| feedback | 玩家的意见反馈（附带队长等级、关卡、场次）。处理完可以把 `done` 改成 `true` |
| saves | 玩家云存档，一人一条（`_id` 是 openid）。**不要手动改** |
| tower | 试炼之塔排行榜 |

## 云存档规则
- 打开游戏时拉取云存档，和本地存档比较，用更新的那份。
- 每次本地保存后 4 秒自动上传；切到后台时立即上传。
- 没网或不在微信里时照常本地玩，下次联网再同步。
