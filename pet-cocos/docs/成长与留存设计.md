# 萌宠守卫战 · 成长与留存设计

所有数值都用 `tools/sim/` 下的模拟器校准过，改数值后建议重跑一遍。

```bash
node --import ./tests/register-ts.mjs tools/sim/retention.mjs 35 16   # 新玩家 35 天，每天 16 场
node --import ./tests/register-ts.mjs tools/sim/required.mjs          # 每关最少需要几倍战力
node --import ./tests/register-ts.mjs tools/sim/pace.mjs 3 16,24      # 指定战力下每段用时
```

## 一、目标节奏

| 指标 | 目标 | 模拟结果（每天 16 场的重度玩家） |
|---|---|---|
| 单局时长 | 6–8 分钟 | 6–9 分钟，无超时僵局 |
| 第 1 天 | 顺利打完第 1 章，建立信心 | 15 胜 1 负，打到 2-8 |
| 推进 | 每天都能推进几关 | 第 5 天 4-8，第 10 天 7-8，第 17 天到 8-8 |
| 队长 | 4–5 周满级 | 第 35 天 26 级 |
| 金币 | 一直有地方花 | 前 12 天基本花完，后期作为升级瓶颈 |

普通玩家（每天约 8 场）大约 5–6 周打通 8 章，之后由试炼之塔接力。

## 二、战力从哪来（战力 = 等级 × 品级 × 队长）

| 来源 | 规则 | 位置 |
|---|---|---|
| 宠物等级 | 每级 +3.5%；**等级上限由品级决定**：凡 15 / 良 25 / 上 35 / 极 45 / 神 55 | `PlayerModel.petBonus`、`GRADE_LEVEL_CAP` |
| 升级费用 | 金币 `80 + 20·Lv^1.8`，经验果 `1 + Lv/4` | `PlayerModel.petUpCost` |
| 品级 | 孵化出的蛋自带品级；同种同品级合成升级（有保底） | `Growth.ts MERGE` |
| 队长等级 | 每级全队 +1.5%；升级经验 `40 + 20·Lv^1.5` | `Growth.ts CAPTAIN`、`PlayerModel.xpToNext` |
| 战斗金币 | `(60 + 40·星 + min(击败,60)) × 关卡倍率 × 活动倍率` | `PlayerModel.applyBattle` |

怪物强度每章约 +5 难度，第 8 章需要约 5.4 倍战力（`tools/sim/required.mjs` 实测）。

## 三、单局结构
- 每关 4 段（首领关最后一段是守护首领），每段约 1 分钟。
- **总攻**：一段超过 90 秒，敌方水晶每秒掉 1%，保证每局都能结束（`SEG.softLimit`、`SEG.overtimeDrain`）。
- 怪物按章节逐步学会针对召唤的机制：破召（第 1 章起）、横扫（第 2 章起）、驱散（第 3 章起），见 `ANTI_SUMMON`。

## 四、留存系统

| 系统 | 作用 | 位置 |
|---|---|---|
| 新手引导 | 第一场战斗手把手（选卡 → 上阵 → 队长技能 → 升级）；回主城后依次引导免费孵化、宠物升级、七日目标 | `Guide.ts`、`BattleSlice.guideStep`、`HomeSlice.homeGuide` |
| 新手七日目标 | 每天 3 个目标 + 当天宝箱，第 7 天宝箱送「小星龙」；目标难度对齐模拟出的正常进度 | `Welfare.ts NEWBIE_GOALS`、福利 →「七日目标」 |
| 七日签到 | 第 7 天送「月绒兔」，之后七天一轮 | `SIGN_NEWBIE` / `SIGN_LOOP` |
| 扫荡 | 三星关卡直接按三星结算（×1 / ×5），刷材料不用重打 | 冒险地图关卡卡片、`PlayerModel.sweep` |
| 试炼之塔 | 无尽爬塔，2 段一层、每 10 层首领；不耗体力，每天 3 次失败机会（胜利不消耗）；首通给奖励。通关 2-8 后开放 | 主城右侧「试炼」、`TOWER` / `towerStage` / `towerReward` |
| 限时活动 | 每周循环：周末金币 ×1.5、周三孵化半价、周五试炼次数 +2；另可按日期配置节日活动 | `meta/Events.ts`，主城顶部活动条 |
| 分享 | 右上角转发 / 朋友圈、胜利后「分享战绩」。**不给奖励**（微信禁止诱导分享） | `Share.ts` |
| 日常 | 每日任务活跃度宝箱、在线奖励、午餐/晚餐体力、免费孵化、训练场与放养挂机 | 原有系统 |
