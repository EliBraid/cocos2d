# 萌宠守卫战 · 实时核心战 原型 v0.1

一局约 4 分钟。上方是敌方核心和两个刷怪口，下方是我方核心。怪物不断刷出、走向我方核心；你在下半场上阵宠物、强化宠物、放技能，守住核心或推掉对面核心。宠物每局都从 Lv.1 开始。

## 玩法规则

| 项目 | 规则 |
|---|---|
| 胜利 | 摧毁敌方核心（我方核心 >60% 三星，否则两星）；或撑满 4:00 守住核心（>60% 两星，否则一星） |
| 失败 | 我方核心血量归零 |
| 上阵 | 点卡片 → 点虚线下方空地；最多 5 只；费用 50 / 100 / 150 / 200 / 250，开局 120 金币 |
| 金币 | 杀怪掉落：毛球怪 8、蘑菇怪 12、角魔 40 |
| 升级① 经验 | 击杀者拿全部经验，140 像素内的队友拿一半；升到下一级需要 3、5、7…… 点 |
| 升级② 强化 | 花金币直接升 1 级，费用 80 + 40×(等级-1)；没选中宠物时强化等级最低的那只 |
| 成长 | 赤焰小狐 设计表数值：生命 1080 (+95/级)、攻击 112 (+12/级)、防御 20 (+2/级)、攻速 1.15；上限 12 级；升级时回 20% 血 |
| 阵亡 | 8 秒后在我方核心旁复活，等级保留 |
| 站位 | 坚守：守在各自站位附近（选中宠物后点空地可调整站位）；进攻：向敌方核心推进，靠近核心时优先打核心 |
| 技能 焰刃 | 8 秒冷却，所有在场小狐向前方扇形挥出火焰，160% 攻击并灼烧 3 秒（每秒 20% 攻击） |
| 刷怪 | 2.6 秒一只逐渐加快到 0.85 秒；每 30 秒一波（4 只起，每 45 秒多 1 只）；每 45 秒一只精英角魔；怪物属性随时间增长；敌方核心半血后刷怪加快 35% |

所有数值集中在 `assets/scripts/battle/BattleConfig.ts`，直接改就能调手感。

## 节奏验证（自动模拟，见 tests/battle.test.mjs）

- 什么都不做：约 1 分钟核心被推掉。
- 只放 1 只不升级：约 1 分半失守。
- 放满 + 强化 + 放技能、一直坚守：守满 4 分钟，两星。
- 养到平均 5 级后转进攻：大约 2:30~3:00 推掉敌方核心拿三星；时机不好会被偷家，只拿一星。

## 代码结构

| 文件 | 作用 |
|---|---|
| `assets/scripts/battle/BattleCore.ts` | 战斗规则（纯逻辑，不依赖引擎，同一个随机种子可复现） |
| `assets/scripts/battle/BattleConfig.ts` | 全部数值 |
| `assets/scripts/BattleSlice.ts` | Cocos 表现层：棋盘、核心、刷怪口、Spine 单位、血条、飘字、金币、卡片、按钮、结算 |
| `assets/scenes/Battle.scene` | 战斗场景（已设为启动场景；营地场景右上角新增“冒险”入口） |
| `assets/resources/battle/` | 棋盘、刷怪口、红色核心、卡片头像、怪物 Spine |
| `tools/minions/` | 怪物部件、骨骼动作、棋盘图的生成脚本（`npm run battle:assets`） |
| `docs/battle/battle-web-preview.html` | 同一套规则的网页版，可直接在浏览器里试玩调数值 |
