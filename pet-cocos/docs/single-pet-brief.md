# 单宠制作范围与验收

本轮沿用用户已指定的主界面参考和赤焰小狐设计，制作可运行的 Cocos Creator 3.8.8 单宠工程。现有原画、旧预览与原作游戏文件保留。

## 视觉与交互

- 视觉：纸白材质、手绘黑线、珊瑚红操作按钮、青色核心、橙色狐狸。版式对应参考图的登录和主城两屏，内容聚焦一只宠物。
- 主界面：顶部玩家/金币/食物、中央营地、底部伙伴与冒险操作、五项导航。界面文字和控件由 Cocos 实现，背景插画用于场景美术。
- 角色：真正 Spine 4.2 数据，柔性部位有加权网格，支持 idle、walk、attack、hit、happy。自动眨眼与行为动画独立。
- 交互：点击地面移动、触摸狐狸回应、训练攻击目标、喂食与升级、查看宠物信息；开启冒险可进入一只宠物的战斗验证场景。局外等级/资源保存在本地，战斗成长从1级开始。
- 场景：受控视角与落地阴影，角色与设施有前后层次，核心发光、风/浮尘等环境动态保持克制。

## 架构来源与边界

复用本轮已核验的原作静态架构证据，不复制原作代码和商业素材。将其状态驱动动画、方向切换、动画事件、材质反馈、可见性更新思路转为自己的模块：

1. GameModel：资源、养成与战斗规则，纯逻辑，可在 Node 测试。
2. PetController：idle/move/attack/hit/happy 的明确状态与目标。
3. PetView：Spine轨道、混合、表情、事件与材质反馈。
4. CampScene/BattleScene：目标、场景层级、特效及3D/2D组合。
5. GameUI：参考图界面、导航、面板和输入。

这不是原作完整架构的复刻。账号/支付/服务器和完整多宠阵容不在单宠样板范围内；未完成的系统不伪装为已联机服务。

## 验收

- Creator工程能够导入，并生成真实Web构建；启动后无资源或脚本错误。
- 狐狸有可检查的网格权重；在 Cocos 中实际播放，动作与角色移动/命中相符。
- 攻击命中事件只结算一次；状态结束能回到正常待机或继续追击。
- 喂食/升级遵守消耗规则，存档恢复；战斗等级与局外培养分离。
- 登录、主城、宠物面板、训练和冒险核心流程可点击完成。
- 在常见竖屏手机尺寸无横向溢出，底部操作可见。

## 结构与检查方式

`assets/scripts/` 为 Cocos TypeScript；`assets/resources/` 为项目自有美术和Spine；`tests/` 为纯逻辑测试；`tools/` 保存素材与构建脚本；`docs/` 保存架构和验证记录。

纯逻辑测试：`node --test tests/*.test.mjs`。

Creator构建命令会在实际编辑器路径确认后写入工程的构建脚本，使用明确的 `--project` 与 `--build` 参数。

始终检查真实运行结果；保留生成提示词和来源；不把独立Web技术预览冒称为Cocos构建；不把没有验证的引擎兼容性当作完成。
