# 微光林地：单狐场景样板 v0.3

视觉方向：奶油色纸张与黑色手绘轮廓组成温暖的森林空地，橙色小狐、金色火光和少量青色晶石作为视觉焦点；夜色下保持角色可读。

内容：一块真实分层的2.5D场景、一只可移动和互动的狐狸、极简竖屏操作。首屏以场景为主，不扩展养成菜单。

动作重点：起步/停止/转向、前后朝向、脚步、蓄力挥剑与恢复、受击、开心、嗅闻、睡眠/醒来。眼睛/嘴/耳朵分开控制，尾巴和围巾存在滞后。原生Cocos Spine 4.2播放。

场景重点：地面、远树、前树、草、石、火把独立摆放；轮廓投影和接触阴影；统一昼夜过渡与局部火光；草丛接触推动、训练靶受击、火焰Spine、火星和飘叶。相机微跟随产生自然景深层次。

验证：逻辑单测验证寻路、状态打断、动画命中去重、草丛进出与光照过渡；真实Creator构建和浏览器交互验证前后朝向、动作/表情、草丛反馈、点地移动、训练命中、昼夜与竖屏适配。保存真实录屏与截图。

范围：制作质量样板，保留现有Camp场景与旧样板源文件，新增Forest场景作为默认入口。沿用原创角色设计与新生成素材；不使用原游戏贴图、骨架、代码或音效。
