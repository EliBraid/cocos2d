## 二、需要你本人处理的

### 1. 账号和 AppID
1. 在 mp.weixin.qq.com 注册**小游戏**账号（个人或企业主体），拿到 AppID。
2. 把 `build-config-wechat.json` 里的 `"appid": "touristappid"` 换成你的 AppID，重新构建。`touristappid` 只能在开发者工具里本地调试，不能上传。

### 2. 资质（以微信公众平台当前要求为准）
- **版号**：游戏要做**虚拟支付（内购）**必须有《网络游戏电子出版物》版号。本游戏目前**没有内购**，只有激励视频广告。
- **软件著作权**：提审时通常要提供软著或相关权属证明，建议尽早申请（周期较长）。
- **广告变现**：开通「流量主」有累计用户数门槛，开通后能否投放广告以后台审核为准。
- 审核细则经常调整，提交前请在公众平台「设置 → 基本设置 / 服务类目」里核对一遍。

### 3. 填写法律文本里的占位符
`assets/scripts/meta/Legal.ts` 里还有 `【运营主体】` 和 `【联系邮箱】`（用户协议第 11、33 行，隐私政策第 56 行），换成真实的公司/个人名称和联系邮箱。用户协议、隐私政策目前标着「草案」，正式版建议找专业人士过一遍。

### 4. 公众平台后台设置
- 「用户隐私保护指引」：按游戏实际收集的信息填写（目前只在本地保存进度，没有上传任何用户数据）。
- 服务类目选「游戏 → 休闲」类，与 8+ 适龄提示保持一致。

### 5. 激励视频广告位
`assets/scripts/Ads.ts` 里的 `AD_UNITS`（`x5` 五倍奖励、`revive` 复活）现在是空的。**空着的时候点“看广告”会直接发奖励**（方便还没开通流量主时也能玩）。开通流量主后把两个广告位 ID 填进去即可；如果不希望白送奖励，告诉我改成“暂无广告”提示。

### 6. 真机测试
1. 微信开发者工具 → 项目 → 导入项目 → 选择 `pet-cocos/build/wechatgame`，AppID 填你的（或先用测试号）。
2. 在模拟器里走一遍：登录 → 主城 → 孵化 → 编队 → 战斗 4 段 → 结算 → 下一关。
3. 点「预览」用手机扫码，至少测一台安卓、一台 iPhone，重点看首次加载时间和战斗帧率。

### 7. 版本号
登录页和设置里显示「版本号 0.3.0」（`HomeSlice.ts` 两处），首发建议改成 1.0.0。

## 三、已知限制（可以上线后再做）
- **存档只在本机**：没有服务器，换手机或删除小游戏会丢进度。`wx.login` 目前只用来走流程，没有用到 code。以后可以接微信云开发做云存档。
- 试炼之塔没有排行榜（需要服务器）。
- 分享不给奖励：微信禁止诱导分享，请不要加“分享得体力”之类的设计。
