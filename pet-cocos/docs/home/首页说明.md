# 萌宠守卫战 · 登录与主城 v0.1

启动场景改为 `Home.scene`：登录 → 主城 → 开始冒险（消耗 5 体力）→ `Battle.scene` → 结算发奖 → 返回主城。

## 登录
标志、标语、营地背景、赤焰小狐（点它会挥剑）、草丛里的怪物、服务器、微信登录、协议勾选（未勾选会提示并抖动）、游客体验、版本号。
在微信小游戏环境里“微信登录”会调用 `wx.login`；目前没有游戏服务器，拿到结果后直接进入。

## 主城
| 区域 | 内容 |
|---|---|
| 顶栏 | 头像（点开设置）、名字、队长等级与经验条、金币、食物、设置 |
| 营地 | 营地原画、发光核心水晶、孵化屋/训练场/工坊木牌、四处走动的赤焰小狐（点它会开心并说话） |
| 右侧 | 邮件（可领一次 200 金币 + 10 食物）、任务（4 个，按真实战绩计进度，可领取）、图鉴，有红点提醒 |
| 出战小队 | 战士位是赤焰小狐，其余 4 个职业位锁定；阵容战力 |
| 关卡卡片 | 晨光森林 3-5 核心攻坚、最好星级、查看路线、开始冒险、体力（每 5 分钟恢复 1 点，上限 80） |
| 底部导航 | 主城、宠物、阵容、背包、冒险（冒险 = 开始冒险，其余页面下一步制作） |

## 局外数据
`assets/scripts/meta/PlayerModel.ts`：金币、食物、体力、队长等级、战绩、任务、邮件，本地存档 `pet-guardians-player-v1`。
每局奖励：金币 = 局内金币 × 0.5 + 星数 × 60；食物 = 胜利 2 + 星数（失败 1）；队长经验 = 20 + 击败数 + 星数 × 15。测试见 `tests/player.test.mjs`。

## 素材
界面元素（标志、标语彩带、木牌、图标、关卡缩略图）由 `tools/home-ui/ui-art.mjs` 生成。
`tools/imagegen/gen-home-art.bat` 用本机 Codex CLI 生成更精细的版本（登录背景、关卡缩略图、标志、图标表），输出到 `art-gen/`，生成后再接入。
